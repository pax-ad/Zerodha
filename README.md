# 📈 Zerodha - Paper Trading Platform

A full-stack paper trading platform inspired by Zerodha that allows users to practice stock trading with virtual money in a realistic environment. The platform is designed to simulate real-world trading while helping users learn market concepts without financial risk.

---

## 🚀 Features

### 👤 Authentication
- User Registration & Login
- Secure Authentication
- Protected Dashboard

### 📊 Trading Dashboard
- Portfolio Overview
- Virtual Balance Management
- Holdings & Positions
- Order History
- Buy & Sell Stocks
- Profit & Loss Tracking

### 📈 Market
- Real-time/Mock Stock Prices
- Search Stocks
- Watchlist
- Stock Details

### 💼 Portfolio
- Current Holdings
- Portfolio Value
- Investment Summary
- Performance Analytics

### 📉 Orders
- Buy Orders
- Sell Orders
- Order History
- Transaction Records

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/pax-ad/Zerodha.git
```

### Frontend

```bash
cd frontend
npm install
npm start
```

### Dashboard

```bash
cd dashboard
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=8000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

> Never upload your `.env` file to GitHub.
